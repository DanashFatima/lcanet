Ontology Specification Draft

Abstract

LCAnet is a modular ontology network for Life Cycle Assessment (LCA) designed to provide a unified semantic framework for representing LCA systems. It is composed of six interoperable modules covering key aspects of LCA modeling: the Core module, Activity module, Actor module, Property module, Spatiotemporal module, and Impact Assessment module. The Core module serves as the central backbone of the network by importing the other modules and establishing explicit semantic links across all components, enabling consistent representation and reasoning over LCA data.

Introduction back to ToC

LCAnet-Spatiotemporal provides classes and properties that enable users to model spatial and temporal aspects of Life Cycle Assessment systems. It represents locations, spatial scales, and temporal entities associated with activities. The module provides contextual information for LCA modelling and is connected to other LCAnet modules through the Core ontology.

LCAnet-Spatiotemporal: Description back to ToC

The Spatiotemporal module is part of the LCAnet ontology proposed by the SmartACV Carnot Project. It provides a formal representation of spatial and temporal aspects relevant to the LCA process, enabling the modeling and integration of location- and time-specific data for products or services. For the temporal aspect, it reuses classes and properties by importing the Time ontology: Time instant, Time interval, and DurationDescription. For the spatial aspect, it aligns with some pre-defined classes from other ontologies such as the Feature class from the geonames vocabulary.
