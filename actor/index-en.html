Ontology Specification Draft

Abstract

LCAnet is a modular ontology network for Life Cycle Assessment (LCA) designed to provide a unified semantic framework for representing LCA systems. It is composed of six interoperable modules covering key aspects of LCA modeling: the Core module, Activity module, Actor module, Property module, Spatiotemporal module, and Impact Assessment module. The Core module serves as the central backbone of the network by importing the other modules and establishing explicit semantic links across all components, enabling consistent representation and reasoning over LCA data.

Introduction back to ToC

LCAnet-Actor provides classes and properties that enable users to model agents involved in Life Cycle Assessment processes. It represents individuals, organizations, or systems responsible for performing or managing activities. The module supports the representation of responsibility and participation in LCA studies and is linked to other LCAnet modules through the Core ontology.

LCAnet-Actor: Description back to ToC

The Actor module is part of the LCAnet ontology proposed by the SmartACV Carnot Project. It provides a formal representation of actors (e.g., persons, organizations, and groups) involved in LCA processes, as well as their roles and responsibilities. It resuses some elements from the FOAF (Friend Of A Freind) ontology.
