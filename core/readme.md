# LCAnet — Core Module

Part of the **LCAnet ontology network** for Life Cycle Assessment.  
🔗 Network landing page: https://w3id.org/lcanet

## Overview
Defines foundational LCA study elements (Goal, Scope, LcaModel, LifeCycleStage) and serves as the semantic integration layer importing all other modules
