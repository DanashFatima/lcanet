Abstract

LCAnet is a modular ontology network for Life Cycle Assessment (LCA) designed to provide a unified semantic framework for representing LCA systems. It is composed of six interoperable modules covering key aspects of LCA modeling: the Core module, Activity module, Actor module, Property module, Spatiotemporal module, and Impact Assessment module. The Core module serves as the central backbone of the network by importing the other modules and establishing explicit semantic links across all components, enabling consistent representation and reasoning over LCA data.

Introduction back to ToC

LCAnet-Core provides classes and properties that enable users to model the overall structure of Life Cycle Assessment (LCA) studies. It defines central concepts such as LCA models, scope, life cycle stages, and interpretation, which organise and coordinate the LCAnet network. It imports and integrates the Activity, Actor, Property, Spatiotemporal, and Impact Assessment modules, providing explicit semantic links between them. This ensures a coherent representation of LCA knowledge across all modules and enables reasoning over the complete LCA workflow.

LCAnet-Core: Description back to ToC

The Core module is the central module of the LCAnet ontology proposed by the SmartACV Carnot Project. It defines the basic elements of a LCA study based on ISO 14040 and ISO 14044 such as the goal, scope, etc. It also imports and links the other LCAnet ontology modules (Activity, Actor, Property, Spatiotemporal, and Impact Assessment) providing an integration layer between the modules. Thus, it serves as a semantic backbone for consistent modeling and reasoning over LCA knowledge.
