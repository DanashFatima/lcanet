Ontology Specification Draft

Abstract

LCAnet is a modular ontology network for Life Cycle Assessment (LCA) designed to provide a unified semantic framework for representing LCA systems. It is composed of six interoperable modules covering key aspects of LCA modeling: the Core module, Activity module, Actor module, Property module, Spatiotemporal module, and Impact Assessment module. The Core module serves as the central backbone of the network by importing the other modules and establishing explicit semantic links across all components, enabling consistent representation and reasoning over LCA data.

Introduction back to ToC

LCAnet-Impact Assessment provides classes and properties that enable users to model environmental impact evaluation in Life Cycle Assessment. It represents impact categories, characterization models, methods, and impact results. The module formalises the assessment of environmental effects and is connected to activities and flows through the Core ontology, enabling structured impact interpretation.

LCAnet-ImpactAssessment: Description back to ToC

The Impact Assessment module is part of the LCAnet ontology proposed by the SmartACV Carnot Project. It provides a formal representation of impact assessment concepts, methods, and characterization factors, enabling the evaluation and quantification of environmental impacts within the LCA process of a product or service.

LCA Resultc back to ToC or Class ToC

IRI: https://w3id.org/lcanet/ia#LcaResult

A LCA result corresponds to the computed value of each flow (or sometimes activity as a group of its input and output flows) concerning an impact category (IC). Thus, it is an entity that makes links to: a flow/activity (e.g. flat chip resistor), an exact value (e.g. 1,16E-03), and an impact category (e.g. climate change), indicating the participation of this flow/activity in the studied impact category issue.
