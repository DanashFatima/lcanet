LCAnet – Life Cycle Assessment Ontology Network

LCAnet is a modular ontology network for Life Cycle Assessment (LCA) designed to provide a unified semantic framework for representing LCA systems and enabling interoperable knowledge modelling.

The ontology is organised into multiple interoperable modules connected through a central Core ontology, enabling structured representation and reasoning across the full LCA workflow.

Architecture Overview

LCAnet follows a modular architecture where each module captures a specific aspect of Life Cycle Assessment. The Core module integrates all components and ensures semantic consistency across the network.

LCAnet modular architecture showing the integration of all ontology modules through the Core.

LCAnet Modules

The ontology is structured into the following interconnected modules:

  • Core module – integrates all modules into a unified framework
  • Activity module – models processes and flows in LCA systems
  • Actor module – represents agents and responsibilities
  • Impact Assessment module – models environmental impact evaluation
  • Property module – represents qualitative and quantitative attributes
  • Spatiotemporal module – models spatial and temporal context

How to use LCAnet

Each module can be explored independently or in combination. The Core ontology ensures integration and semantic alignment across all modules, enabling coherent LCA modelling workflows.
