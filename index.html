Architecture Overview

LCAnet is a modular ontology network for Life Cycle Assessment providing a unified semantic framework for interoperable knowledge modelling across the full LCA workflow. It follows a modular architecture where each module captures a specific aspect of Life Cycle Assessment. The Core module integrates all components and ensures semantic consistency across the network.

LCAnet Modules
