Ontology Specification Draft

Abstract

LCAnet is a modular ontology network for Life Cycle Assessment (LCA) designed to provide a unified semantic framework for representing LCA systems. It is composed of six interoperable modules covering key aspects of LCA modeling: the Core module, Activity module, Actor module, Property module, Spatiotemporal module, and Impact Assessment module. The Core module serves as the central backbone of the network by importing the other modules and establishing explicit semantic links across all components, enabling consistent representation and reasoning over LCA data.

Introduction back to ToC

LCAnet-Property provides classes and properties that enable users to model qualitative and quantitative characteristics of LCA entities. It represents attributes such as quantities, units, and data quality indicators. The module enriches the semantic description of activities and flows and is integrated into the LCAnet network through the Core ontology.

LCAnet-Property: Description back to ToC

The Property module is part of the LCAnet ontology proposed by the SmartACV Carnot Project. It provides a formal representation of qualitative and quantitaive properties to LCA processes and flows, enabling the description of LCA data for products or services.
